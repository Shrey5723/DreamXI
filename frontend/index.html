Theoretical Complexity Analysis of DreamXI Modules
0/1 Knapsack DP
Time: O(N · States) ≈ O(N · 990K)
Space: O(States + N · States / 8)

Guarantees global maximum fantasy points across 6 simultaneous constraints. Backtracks via bitset.

Greedy Heuristic
Time: O(N log N)
Space: O(N)

Picks by points/credit ratio. Fast but susceptible to budget traps, leaving sub-optimal residual credits.

Augmented Treap
Rank: O(log N) | Top-K: O(log N + K)
Space: O(N)

BST ordered by score with randomized heap priorities. Subtree size augmentation enables order-statistic lookups.

Binary Min-Heap
Time: O(N log K)
Space: O(K)

Bounded capacity K heap retains highest form players in a single pass without sorting the remaining N-K items.

Disjoint Set Union
Find & Unite: O(α(N)) ≈ O(1)
Space: O(N)

Path compression flattens trees on lookup; union-by-rank balances depths, yielding inverse Ackermann time.
